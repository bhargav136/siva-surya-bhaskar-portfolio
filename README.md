# Siva Surya Bhaskar Dulam — Portfolio Website

A fast, responsive, and editorial portfolio website designed for **Siva Surya Bhaskar Dulam**, B.Tech Artificial Intelligence student at Sri Vasavi Engineering College.

## 🚀 Features

- **Accurate & Resume-Grounded**: Every section is strictly curated directly from Siva Surya Bhaskar Dulam's resume.
- **Editorial & Modern Design**: Typography inspired by contemporary design with Fraunces, DM Sans, and DM Mono.
- **Light & Dark Mode**: Seamless theme switcher with persistence in `localStorage`.
- **Selected Work**: Showcases the AI-Powered CCTV Surveillance System, SIH26165 Safety Intelligence solution, and CampusLoop platform.
- **Milestones & Hackathons**: Highlights accomplishments in Nexus 2K26 (SYNOVA, War With Wisdom), Smart India Hackathon 2026, GDG Hackathon Top 10, and SQUID GAME 2 (24h).
- **Interactive Details**: 1-click clipboard copy for email and phone number, clean mobile drawer navigation, accessible skip links, and semantic tags.
- **Zero Dependencies**: Pure HTML5, CSS3, and JavaScript — loads instantly, achieves 100/100 performance, and is ready for 1-click deployment on Vercel.

## 🌐 Deploy to Vercel

### Option 1: Via Vercel Web Dashboard (Recommended)
1. Push this repository to GitHub under your desired GitHub account.
2. Go to [vercel.com/new](https://vercel.com/new) and select the repository.
3. Click **Deploy**. Vercel will automatically detect the static site and deploy it within seconds.

### Option 2: Via Vercel CLI
```bash
vercel login
vercel --prod
```
